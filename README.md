# 哥伦布手机套餐横向对比

美国俄亥俄州哥伦布市（Columbus, OH）手机资费的严谨横向对比。**9 个品牌 / 46 个套餐档位**，
覆盖单线自带手机（BYOD）、多线拼卡、合约购机三种场景。

成品是一个**完全自包含的单文件 HTML**，双击即开，无外部依赖、无网络请求：

价格口径日期：**2026-08-14**。全部数据来自当天对各运营商官网的实际抓取。

## 这份东西解决什么问题

美国手机资费的横向对比几乎全是错的，因为**大家在拿不可比的数字排名**：

- 有的品牌标价含税，有的另计——俄亥俄的税费在低价档能吃掉 **40%**；
- 有的报 AutoPay 折后价，有的报折前价；
- 首月促销价被当成常规价；年付摊算价被当成月付价；
- 「无限」至少有五种互不相同的含义。

所以这份对比的地基是一个换算：把所有价格拉平成**到手价**（你银行卡实际被扣的数字），再排序。

### 到手价换算公式（俄亥俄 / 哥伦布）

```
到手价 = 广告价 × 1.2359 + 每线固定费 + $0.25
```

| 项 | 值 | 说明 |
|---|---|---|
| 政府税费 | **23.59%** | 州+地方 9.20% + 联邦 USF 14.39% |
| 每线固定费 | Verizon `$3.99` / AT&T `$4.99` / T-Mobile `$4.49` | **不是税**，是运营商自收费；不受任何价格锁保护 |
| NG911 | `$0.25`/线/月 | 俄亥俄州固定额 |

**倍率随档位递减**（固定费不随价格缩放）：`$25` 档 ×1.45、`$50` 档 ×1.34、`$90` 档 ×1.29。
不存在单一的「×1.3」——套餐越便宜，税费咬得越狠。

> **一处对权威数据的修正**：Tax Foundation 2025 版给俄亥俄的合计税率是 22.56%，但它用的是 2025 年三季度的
> 联邦 USF 缴费系数（36.0%）。FCC 已于 2026-06-15 核准 Q3 2026 系数为 **38.8%**（历史最高）。
> 按 38.8% × 37.1% 安全港 = 14.39%，俄亥俄实际应为 **23.59%**。直接抄 Tax Foundation 会低估约 1 个百分点。

换算的效果很直接：**同样标价 $25，Cricket / Total Wireless / Visible / Metro / US Mobile 到手就是 $25，
而 AT&T 预付费到手 $33.78。** 这个差距在原始报价表里完全看不出来。

## 重建

```bash
python3 src/build.py
```

输出到仓库根目录。也可以指定路径：

```bash
python3 src/build.py ~/Desktop/输出.html
```

只需要 Python 3 标准库，无第三方依赖。

### 文件职责

| 文件 | 作用 |
|---|---|
| `src/build.py` | 渲染主程序：到手价计算、各章节 HTML 生成 |
| `src/tpl.py` | CSS + 页面骨架 + 交互 JS（价格轴泳道排布、同价位匹配） |
| `src/data_plans.py` | 9 个品牌 46 个套餐的逐档数据 |

但税率、USF 系数、运营商自收费同样会变（AT&T 的管理费八个月内涨了两次），重做时都要重新核。

## 方法与可信度

- 全部价格来自 **2026-08-14 当天**对官网的实际抓取，不使用任何记忆中的数字。
- 严格区分三种价格：常规牌价 / AutoPay 折后价 / 限时或条件促销价。促销价单列并标注失效日，**不参与主排序**。
- 严格区分**官方点名**与**第三方推断**。例如 Cricket 官方点名 AT&T、Visible 与 Total Wireless 官方点名 Verizon，
  这三家可以当事实写；而 **Spectrum、US Mobile、Google Fi 三家官网全站不点名任何底层运营商**，
  所有「Warp = Verizon」之类的映射都只能标为第三方推断。
- **查不到就写「未找到」，绝不推测填空。** 页面第 11 节列出了全部未能核实的字段。

### 已知的空缺

- Total Wireless 的非 AutoPay 牌价（官网只印 AutoPay 价）
- Total 的 200+ 国际目的地清单是否含中国大陆（页面动态加载，未渲染）
- US Mobile 热点超额后的速度（官网四处均无）
- Metro 的 2/3/5 线官方每线价（查过 7 个官方页面均未刊登）
- Mint Mobile 的网络归属与 50GB 阈值（抓取时返回 HTTP 403，未取得官网原文）
- 论坛口碑（Reddit 在抓取环境中全程不可访问，因此页面内**不含任何论坛传闻**）

## 免责

这不是理财或消费建议，也不能替代你自己在结账页的核对。运营商页面会按地址、登录状态、是否携号转入、
设备、AutoPay、付款方式和宽带绑定动态变化——**下单前必须在结账页再确认一次总价**。

到手价是估算，误差带 **±3~6 个百分点**，最大误差源是联邦 USF 的安全港口径。

覆盖是逐街区的事：都会区级别的路测和 FCC 面积覆盖**不能**替代你在住处、教室、办公室和通勤路线上的实测。
